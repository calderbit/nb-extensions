# NetBird VPN Cinnamon Applet

Cinnamon panel applet for NetBird VPN.

## Requirements

- Cinnamon 5.4+
- NetBird installed

## Install

Copy `netbird@netbird.io/` to `~/.local/share/cinnamon/applets/`:

```bash
cp -r netbird@netbird.io ~/.local/share/cinnamon/applets/
```

## Enable

Right-click panel > Applets > search "NetBird" > Add

Or use the installer:

```bash
bash install.sh --cinnamon
```
